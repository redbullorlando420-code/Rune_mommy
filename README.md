# Rune Mommy

Click-to-walk multiplayer MMO. Chat, trade, skills, combat.

Clermont town is seeded with 10 real DoorDash shake spots near Sanctuary Dr.

## The shake row

## Run

```bash
npm install
npm start
```

Then open http://localhost:3333 in two browsers.
